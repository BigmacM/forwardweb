How will your title and description look in search?

Your title and description as a search result, measured in pixels rather than guessed in characters.

Snippet previewRuns in your browser

This tool needs JavaScript to measure text in pixels. As a rule of thumb, keep titles under about 60 characters and descriptions under about 155.

What this checks

The pixel width of your title and description in a typical search-result font, against the usual limits of about 600 pixels for a title and about 920 for a description on desktop.

The gotcha

The limits are approximate and Google rewrites snippets when it thinks it can do better. Treat the bars as a guide to where text is likely to be cut, not a guarantee.

What it can't see

It cannot see how Google will actually rewrite your snippet, and it measures in one font, so results on a device with a different font can differ a little.

QuestionsShort answers.

Why pixels and not characters?

Search results truncate by width. A title of capital Ws is far wider than the same number of lowercase i letters, so character counts mislead.

Will Google use my description?

Often not. Google picks text from the page when it matches the query better. A clear description still helps when it does use yours.
