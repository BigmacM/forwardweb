What this checks

Each major AI crawler against your rules, using the same group-matching logic crawlers use: a bot follows the group that names it, and falls back to the wildcard group only if none does.

The gotcha

A bot with its own group ignores your wildcard group completely. The common advice to add "Allow: GPTBot" can reopen the very paths you blocked for everyone else.

What it can't see

It reads only what you paste. It cannot tell whether a bot actually visits, or whether your server blocks it some other way.

QuestionsShort answers.

Should I allow AI crawlers at all?

If you want to be recommended by AI assistants, they need to be able to read you. Blocking is a legitimate choice for publishers who do not want their work used for training, but for most small businesses it removes you from the answers.

What is the difference between training and search bots?

Some companies run separate crawlers for model training and for live answers or search. The table lists them separately so you can allow one and block the other. Check each company's own documentation for the current names.

Does robots.txt actually stop a bot?

It is a request, not a lock. Reputable crawlers honour it. Anything private needs real access control, such as a login, and not a line in a text file.
