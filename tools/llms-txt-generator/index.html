What is llms.txt, and should your site have one?

Build the file in a minute. My honest note: no major assistant has confirmed it uses the file.

llms.txt generatorRuns in your browser

This generator needs JavaScript. It writes a plain markdown file from the details you type, in your browser.

Format: Title | address | short note. The note is optional.

Your llms.txt

Upload it to the root of your site so it is reachable at yourdomain.com/llms.txt. As far as I know, no major assistant has confirmed it reads the file.
What this checks
It takes your site name, a short summary and your key pages, and writes a plain markdown file in the shape the llms.txt proposal describes, ready to download.
The gotcha
As far as I know, no major AI assistant has confirmed that it reads llms.txt. The file is harmless and takes minutes, so I treat it as optional housekeeping, not a strategy.
What it can't see
It cannot make an assistant read the file, and it does not check that your links work. It writes the text you give it.
QuestionsShort answers.
Will llms.txt get me recommended by ChatGPT?
I have no evidence that it will. No major assistant has said it uses the file. Clear pages, open crawler access and consistent facts do more.
Where does the file go?
At the root of your site, so it is reachable at yourdomain.com/llms.txt.
Is it worth making anyway?
It costs a few minutes and does no harm, and it forces you to write down what your site is about. That alone is a useful exercise.
